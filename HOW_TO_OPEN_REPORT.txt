STEP 1: Locate the Compiled Output Asset
-----------------------------------------

--> reports/
Inside this target directory, locate the master dashboard report file:
--> complete_automation_report.html

STEP 2: Open using any Contemporary Web Browser
------------------------------------------------
Right-click on 'complete_automation_report.html', select "Open With", and 
choose your preferred production web browser environment:
* Google Chrome
* Microsoft Edge
* Mozilla Firefox
* Apple Safari

--------------------------------------------------------
As soon as the interactive interface expands in your browser view, you will 
be presented with:
1. Summary Matrix Table: Displays certified repository metadata metrics

3. Expanded Execution Trace Logs: Click on any specific test script row (e.g., 
   CSS validation, explicit wait gates, or Requests API responses) to 
   instantly expand the runtime parameters, input fixtures, and step logs.

*Note: Ensure the local application server is active at http://127.0.0.1:5000
